
# 📚 Proyecto Estructuras de Datos - Tercer Semestre

Este proyecto fue desarrollado para la materia de **Estructuras de Datos** del tercer semestre de **Ingeniería de Software**. El objetivo de este proyecto es implementar diversas estructuras de datos en **Java**, como listas circulares, listas simples, pilas, nodos y más.

## 🛠 Estructuras Implementadas

El proyecto incluye las siguientes estructuras y clases:

### 1. **🔄 Lista Circular**
- **`ListaCircular.java`**: Implementación de una lista circular, donde el último nodo apunta al primero.
- **`Nodo.java`**: Clase que representa un nodo de la lista circular.

### 2. **🔗 Lista Simple**
- **`ListaSimple.java`**: Implementación de una lista simple donde cada nodo apunta al siguiente.
- **`Nodo.java`**: Clase que representa un nodo en la lista simple.

### 3. **🌀 Pilas**
- **`Pilas1.java`**: Implementación de una pila con operaciones básicas como `push`, `pop`, y `peek`.
- **`Pila.java`**: Clase que representa la estructura de una pila.

### 4. **🔤 Conteo de Letras**
- **`ConteoLetras.java`**: Programa que cuenta la frecuencia de las letras en una cadena de texto.

### 5. **📑 Otros Archivos**
- **`Principal.java`**: Clase principal donde se testean o ejecutan las operaciones de las estructuras.
- **`arrays.java`**: Implementación y manejo de arrays.
- **`lista.java`**: Implementación básica de una lista (puede referirse a una lista ligada simple o similar).
- **`nodo.java`**: Clase que representa un nodo genérico (usado en varias estructuras).
- **`estrucurapila.java`**: Implementación de una pila con su estructura.

## 💻 Tecnologías Utilizadas

- **Java**: Lenguaje de programación utilizado para implementar las estructuras.
- **IDE**: (Por ejemplo, IntelliJ IDEA o Eclipse) para desarrollar el código.

## 🚀 Uso

Para probar las implementaciones, puedes ejecutar la clase **`Principal.java`**, que contiene los métodos principales de prueba.

```bash
java Principal
```

### 📝 Operaciones Disponibles:

- **Lista Circular**: Crear, agregar, eliminar nodos, recorrer la lista circular.
- **Lista Simple**: Insertar y eliminar nodos.
- **Pilas**: Realizar operaciones de apilado (`push`), desapilado (`pop`), y visualización (`peek`).
- **Conteo de Letras**: Contar cuántas veces aparece cada letra en una cadena.
